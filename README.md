# 🍲 Food Kaatha - Full Stack Web App

Track daily food transactions in your shop — for both immediate payments and *Katha* (credit).

> Built with Node.js, Express, MongoDB, Tailwind CSS  
> Deployed using Render & MongoDB Atlas

## 🧰 Features

- ✅ Add new transactions (Paid / Katha)
- ✅ Customer name, item list, total amount
- ✅ Search transactions by customer
- ✅ Stored permanently in MongoDB
- ✅ Hosted on a single server (backend + frontend)

---

## How Katha credit tracking works

Small food shops often let regular customers eat now and pay later. In this app, every transaction is recorded as either **Paid** (settled immediately) or **Katha** (credit owed by that customer). Because each entry carries the customer name, items and total, the shop can look up any customer and see exactly what they owe — no paper ledger needed.

## 🚀 Local Development

### 1. Clone the repo

```bash
git clone https://github.com/alphathehacker/foodkaathabook.git
cd foodkaathabook
```

### 2. Install and run

Install dependencies, set your MongoDB connection string in a local `.env` file (never commit real credentials), then start the server and open the app in your browser.
